# Day 2 Visual — Files & Directories

## Filesystem actions

```text
                         mkdir
                   create directories

          touch                         cp
      create empty files              copy

                       FILESYSTEM

           mv                           rm
     move / rename                  remove
```

## Action flow

```text
create
  ↓
mkdir / touch
  ↓
copy
  ↓
cp
  ↓
move / rename
  ↓
mv
  ↓
remove
  ↓
rm
```

## Safety note

```text
rm file.txt
    ↓
remove one file

rm -r directory
    ↓
remove a directory and everything inside it
    ↓
VERIFY THE PATH FIRST
```

This visual contains only commands and concepts practiced in Day 2.
