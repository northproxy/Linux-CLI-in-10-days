# `touch`

## Purpose

For this project, use `touch` to create an empty file for practice.

## Syntax

```bash
touch file...
```

## Useful variants

### Create one empty file

```bash
touch notes.txt
```

### Create several empty files

```bash
touch notes.txt todo.txt
```

### Create a file using a path

```bash
touch documents/report.txt
```

The parent directory must already exist.

## Hover / tap meanings

```text
touch file
Create an empty file when it does not already exist.
```

## Input

File name or path.

## Output

Normally no output on success.

## Related tasks

- create an empty practice file;
- create several files;
