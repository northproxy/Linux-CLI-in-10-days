# `cat`

## Purpose

Display file contents directly in the terminal.

## Syntax

```bash
cat FILE
```

## Useful usage

```bash
cat system-notes.txt
```

## Meaning

`cat` prints the contents of the file to standard output.

It is most convenient for short files.

## Input

A text file.

## Output

The complete file contents.

## Hover / tap meaning

```text
cat FILE
Show the complete contents of a file.
```

## Example

```bash
cat config.txt
```

## Related tasks

- Read a small text file
- Inspect a short configuration file

## Related concepts

- text files
- standard output
- file content
