# `less`

## Purpose

Browse a text file interactively without printing the whole file at once.

## Syntax

```bash
less FILE
```

## Useful controls

```text
↓ / ↑   move through the file
q       quit
```

## Meaning

`less` is useful when a file is too long to read comfortably with `cat`.

## Input

A text file.

## Output

An interactive file view in the terminal.

## Hover / tap meaning

```text
less FILE
Browse a file interactively.
```

## Example

```bash
less system-notes.txt
```

Exit with:

```text
q
```

## Related tasks

- Read a long file
- Inspect documentation
- Browse configuration or log files

## Related concepts

- interactive terminal programs
- text files
