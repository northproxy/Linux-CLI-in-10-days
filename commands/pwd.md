# `pwd`

## Purpose

Print the absolute path of the current working directory.

## Syntax

```bash
pwd
```

## Useful variants

For Day 1, use the basic command without options:

```bash
pwd
```

## Hover / tap meaning

```text
pwd
Print the current working directory.
```

## Examples

```bash
pwd
```

Example output:

```text
/home/sadmin
```

## Input

No file input is required.

`pwd` reads the shell's current working-directory context.

## Output

An absolute filesystem path.

Example:

```text
/home/sadmin
```

## Safety

Safe for normal use. It only reports the current location.

## Related tasks

- Check where you are before navigating.
- Confirm the result of a `cd` command.
- Verify whether a relative path will start from the expected directory.
